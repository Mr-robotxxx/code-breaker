🎮 How to Play:

  • Select a difficulty level (4-8 digits). Higher levels give more points!
  • You have 10 attempts to guess the secret code.
  • After each guess, you'll get feedback:
    • Correct Position: Digits that are correct and in the right position.
    • Correct Number: Digits that are correct but in the wrong position.
  • When you complete a level, you earn Hacker Points based on difficulty.
  • Use Hacker Points to reveal digits (max 2 per level):
    • Level 1 (4 digits): 5 points each
    • Level 2 (5 digits): 10 points each
    • Level 3 (6 digits): 25 points each
    • Level 4 (7 digits): 50 points each
    • Level 5 (8 digits): 100 points each
  • Free hints appear after 7 and 9 wrong attempts.
  • Buy extra attempts for 50 points each when low on attempts.
  • Game Over shows the solution so you can see how close you were!
  • Points persist between games and can be used anytime.
  • If you guess the code correctly: you'll unlock an achievement!
  • Different achievements for different difficulty levels.
  • Click "Install App" button to download and play offline!
  • Click "New Game" to start over with a new random code.
