# Code Breaker: Hacker Challenge 🎮

A challenging code-breaking puzzle game that you can install and play offline!

## 🎯 How to Play
1. Select a difficulty level (4-8 digits)
2. You have 10 attempts to guess the secret code
3. After each guess, you get feedback:
   - **Correct Position**: Digits that are correct and in the right position
   - **Correct Number**: Digits that are correct but in the wrong position
4. Earn Hacker Points by completing levels
5. Use points to reveal digits (5 points each)
6. Try to beat your high score!

## 📱 Install as App
This game is a Progressive Web App (PWA). You can install it on your device:

### **Android (Chrome):**
1. Visit the game URL
2. Tap menu (⋮) → "Install app" or tap the "Install App" button
3. The app will install like a native app

### **iOS (Safari):**
1. Visit the game URL
2. Tap share button (📤)
3. Scroll down → "Add to Home Screen"
4. Name it "Code Breaker" and tap "Add"

### **Desktop (Chrome/Edge):**
1. Visit the game URL
2. Look for install icon (⬇) in address bar
3. Or click the "Install App" button

## 🚀 Features
- ✅ **Fully offline** - Play without internet
- ✅ **Save games locally** - Progress is saved automatically
- ✅ **Export/Import saves** - Backup your game data
- ✅ **Multiple difficulty levels** - 4 to 8 digit codes
- ✅ **Achievement system** - Unlock titles for each level
- ✅ **Points system** - Earn and spend Hacker Points
- ✅ **Responsive design** - Works on all devices
- ✅ **No ads, no tracking** - Just pure gaming fun!

## 🎮 Controls
- Use number keys or click/tap to enter digits
- Press Enter to submit guess
- Use Tab or arrow keys to navigate between inputs
- Click "New Game" to restart

## 🔧 Technical Details
- Built with HTML5, CSS3, and vanilla JavaScript
- Uses Service Workers for offline capability
- localStorage for game saves
- PWA-ready with manifest and icons
